# v7.20.2

## Summary

This patch release fixes the missing speaker/play icons in packaged builds and
keeps the `v7.20.1` MV3/runtime hardening and mainland-friendly default preset
intact.

## Highlights

- Fixed packaged speaker icon rendering:
  - corrected the speaker SVG asset path in the built CSS pipeline
  - speaker/play controls now render again while keeping existing playback logic
- Kept the `v7.20.1` release-state changes:
  - mainland-user-first default preset
  - Google Translate kept as the default phrase/sentence translator
  - empty dict items stay collapsed by default
  - missing machine-translation credentials show as credential-required
  - shared-browser MCP path remains the preferred verification lane

## Verification

- `npm run build`
- `npm run test:bdd-gate`
- `npm run test:required`

## Install

- GitHub release page:
  - https://github.com/JoJoJoinme/ext-saladict/releases/tag/v7.20.2
- Download package:
  - `saladict-7.20.2-chrome.zip`

Manual install:

1. unzip the package
2. open `chrome://extensions` or `edge://extensions`
3. enable Developer mode
4. choose `Load unpacked`
5. select the unzipped extension directory
