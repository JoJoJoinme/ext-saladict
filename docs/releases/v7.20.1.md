# v7.20.1

## Summary

This release hardens the Chrome/Edge MV3 runtime, makes the MCP/shared-browser
verification path practical again, and retunes the default dictionary preset
toward a mainland-user-first experience while keeping Google Translate as the
default phrase/sentence translator.

## Highlights

- Hardened PDF sniffing in MV3:
  - synchronized sniffer state for acceptance/runtime config changes
  - handled `.pdf` URLs even when `content-type` is missing
  - added fallback handling for direct tab updates and `tabId = -1`
- Fixed service-worker analytics/runtime issues:
  - service-worker-safe page context checks
  - background analytics now use `fetch`
  - analytics respect stored config before any network call
- Repaired MCP/browser verification workflow:
  - shared Chrome for Testing lane is now the preferred repo-local MCP path
  - added tmux-hosted shared-browser wrapper scripts and docs
  - documented fresh `codex exec` verification flow for reloaded MCP config
- Improved lookup UX:
  - empty dictionary items no longer auto-expand by default
  - missing machine-translation credentials now show as credential-required
    instead of fake empty results
- Retuned default preset:
  - kept `bing`, `cambridge`, `youdao`, `vocabulary`, `zdic`, `guoyu`,
    `liangan` for single-word lookup
  - kept `google` as the default phrase/sentence translator
  - removed weak or token-dependent translators from the default preset
  - added legacy default-preset migration for untouched stored profiles

## Notes

- This branch targets Chrome / Edge MV3.
- Firefox / Safari manifests are not maintained in this release line.

## Install

- GitHub release page:
  - https://github.com/JoJoJoinme/ext-saladict/releases/tag/v7.20.1
- Download package:
  - `saladict-7.20.1-chrome.zip`

Manual install:

1. unzip the package
2. open `chrome://extensions` or `edge://extensions`
3. enable Developer mode
4. choose `Load unpacked`
5. select the unzipped extension directory
